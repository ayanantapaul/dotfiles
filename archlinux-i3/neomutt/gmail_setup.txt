Setup Neomutt with Gmail (direct IMAP, no local mail storage)
-------------------------------------------------------------

--- step 1 (install packages) ----

-- for Debian/Ubuntu --

  $ sudo apt update 
  $ sudo apt upgrade 
  $ sudo apt install neomutt isync msmtp msmtp-mta pass gnupg 

-- NOTE --
If prompted "Enable AppArmour Support?" during installation, choose "YES".
It only adds a security confinement profile for the package; no downside.

---- step 2 (generate Gmail app password) ----
1. Go to Google Account -> Security 
2. Confirm 2 Step Verification is ON (required)
3. Go to Security -> App Passwords (or myaccount.google.com/apppasswords)
4. Create a new app password, name it e.g. "neomutt" (you can name it anything you want)
5. Copy the 16-character password shown, without spaces (no spaces when using it)
   Keep this handy for step 3.

---- step 3 (secure the app password with gpg) ----

-- step 3a (generate a gpg key, skip if one already exits) --

  $ gpg --full-generate-key

  - Key type: RSA and RSA (default)
  - Key size: 4096
  - Expiry: 0 (does not expire) or your preference
  - Real name: your_name
  - Email: your_gmail_adress
  - Set a passphrase (you will need this later to decrypt)

-- step 3b (save the password in a temporary file) --

  $ echo "your-16-char-app-password" > mbsync.pw

-- step 3c (now encrypt it) --

  $ gpg --encrypt --recipient "your.email@gmail.com" mbsync.pw

-- step 3d (move the encrypted file some where safe and delete the plain text) --

  $ mv mbsync.pw.gpg ~/.mbsync-pw.gpg
  $ rm mbsync.pw

-- step 3e (verify the decryption works) --

  $ gpg --quiet --for-your-eyes-only --no-tty --decrypt ~/.mbsync-pw.gpg
  (should prompt for GPG passphrase, then print the app password)

---- step 4 (configure neomutt, direct IMAP no local storage) ----

-- step 4a (create config directory) --

  $ mkdir -p ~/.config/neomutt/
  
-- step 4b (create a file called "neomuttrc" in "~/.config/neomutt/" directory and copy & edit the content from my github repository as per your requirements) --

  $ cd ~/.config/neomutt/
  $ touch neomuttrc

-- step 4c (launch neomutt) --

  $ neomutt 

  - prompts for gpg passphrase to decrypt app password 
  - you should see your all mail section if you followed all the steps correctly 

---- step 5 (configure msmtp for sending mail) ----

-- step 5a (create ~/.msmtprc with the following content) --

  $ touch ~/.msmtprc

  (then copy & paste the following content)

  ----------
  defaults
  tls on
  tls_trust_file /etc/ssl/certs/ca-certificates.crt
  logfile ~/.msmtp.log

  account gmail
  host smtp.gmail.com
  port 587
  auth on
  tls_starttls on
  from your.email@gmail.com
  user your.email@gmail.com
  passwordeval "gpg --quiet --for-your-eyes-only --no-tty --decrypt ~/.mbsync-pw.gpg"

  account default : gmail
  ----------

-- step 5b (lock down file permission) --

  $ chmod 600 ~/.msmtprc 

-- step 5c (test sending) --

  $ echo -e "Subject: test\n\nhello from msmtp" | msmtp your.email@gmail.com

  - Prompts for GPG passphrase
  - No output = success
  - Check inbox for the test email

-- step 5d (check log if it fails) --

  $ cat ~/.msmtp.log

---- Step 6 (configure with git send-email) ----

-- step 6a (install git) --

  $ sudo apt install git 

-- step 6b (configure ~/.gitconfig) -- 

  $ touch ~/.gitconfig

  (and then paste the following text into it or edit it)
  ----------
  [user]
          email = your.email@gmail.com
	  name = your_name

  [sendemail]
          smtpserver = /usr/bin/msmtp
          smtpserveroption = --account=gmail
  ----------

----- Congratulations btw! (if you did every thing correctly) -----

result / what this setup give you 
---------------------------------
- neomutt reads mail directly from Gmail via IMAP, no local mail files saved
- msmtp sends mail through Gmail's SMTP using the same encrypted app password
- Gmail App Password stored once, encrypted with GPG, reused by both tools
- ready to link with git send-email (separate step) using the same msmtp account
